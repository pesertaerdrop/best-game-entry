**Lumen Run** — Pip the fox cub dashes 1,000 m through the night forest to the lighthouse. Three lanes, one jump, one slide: jump the rocks, slide under the thorn arches, dodge the boulders that block a whole lane, and catch fireflies to build a combo. Three hearts, rising speed, a star shield and rare heart drops. Keyboard, mouse and touch; all art is drawn on canvas and all sound is synthesised with WebAudio — no network, no assets.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static file server and open `game/index.html`.
